# Wiki da Mulher Brasileira

### Plataforma de Dados sobre a Mulher Brasileira

O **Wiki Mulher Brasileira** é um projeto de dados dedicado à organização, integração e análise de informações públicas sobre as mulheres no Brasil.

O objetivo é facilitar o acesso a indicadores demográficos, sociais e territoriais, reunindo dados de fontes oficiais.

---

## Arquitetura dos Dados

| Camada | Descrição |
|---|---|
| RAW | Dados originais ingeridos das fontes |
| REFINED | Dados padronizados e tratados |
| STAGING | Transformações, agregações e integração |
| AUGMENTED | Indicadores e modelos finais para análise |

## Domínios de Dados

- **População (pop):** distribuição demográfica por território e faixa etária.
- **Favelas (fav):** população residente em favelas e comunidades urbanas.
- **Alfabetização (alfa):** indicadores de alfabetização da população feminina.
- **Localização (loc):** organização geográfica por município e UF.
- **Indígenas (ind):** povos originários, população indígena.


## Fontes

**IBGE — Instituto Brasileiro de Geografia e Estatística**

Dados do Censo Demográfico utilizados na construção de indicadores populacionais e territoriais.

## Explorar os Dados

Utiliza o menu lateral para navegar pelos modelos, consultar os dicionários de colunas e explorar o lineage das transformações.
